Parking System
REST API сервис для управления парковкой. Приложение позволяет регистрировать транспортные средства, управлять доступными парковочными местами и отслеживать сессии парковки (въезд и выезд) с автоматическим расчетом стоимости услуг в зависимости от типа автомобиля.

Требования для запуска
Java: JDK 21.0.10

Сборщик: Maven

Контейнеризация: Docker (для локального запуска базы данных)

Настройка и запуск базы данных (Docker)
Для работы приложения требуется PostgreSQL. Самый быстрый способ поднять базу с нужными конфигурациями — использовать Docker.

Выполните в терминале следующую команду (она создаст и запустит контейнер с нужным названием БД, пользователем и паролем):

Bash
docker run --name parking-postgres \
-e POSTGRES_DB=parking_system_test \
-e POSTGRES_USER=postgres \
-e POSTGRES_PASSWORD=postgres \
-p 5432:5432 \
-d postgres:15-alpine
